## โครงการและสถานะ

Monk Chat Guide เป็นเว็บแอป PWA สำหรับสนับสนุนกิจกรรม Monk Chat ผู้ใช้หลักคือพระนิสิตที่เตรียมตัวสนทนาและนำนั่งสมาธิแก่ชาวต่างชาติ มีพื้นที่ข้อมูลสาธารณะและหลังบ้านจัดการเนื้อหา ใช้ไทยเป็นหลัก สลับอังกฤษได้ งบระบบ0บาท Supabase Free และ Cloudflare Pages Free

เว็บและภาคนิพนธ์ปรับให้สอดคล้องกันแล้ว เจ้าของย้ำให้คงธีม การ์ด ภาพ วัตถุประสงค์และวิธีวิจัย ไม่รื้อระบบหรือขยายงานเอง ภาคนิพนธ์เป็นฉบับก่อนเก็บข้อมูลภาคสนามตามแผน27,30พฤศจิกายนและ4ธันวาคม2569 ยังไม่ใช้mockupหรือคะแนนเกมเป็นผลประเมินผู้ใช้จริง

งานCMSหน้าHome/Activitiesเผยแพร่เว็บจริงแล้ว26พฤศจิกายน อัปโหลดรูป แก้เนื้อหา บันทึกร่าง ดูตัวอย่าง เผยแพร่ และคืนค่าได้ ทดสอบภาพบนหน้าเว็บแล้วคืนภาพเดิมแล้ว งานที่ยังไม่commitต้องรักษาไว้

## งานหลักที่1: หน้าสมาธิสองหน้า

เจ้าของลองmockupแล้วให้ลงเว็บจริง ปัจจุบันลงsourceและผ่าน178testsแล้ว เปิดในเครื่องได้ ยังไม่deploy

1. คู่มือเริ่มต้น: ใช้การ์ด ภาพ และสามช่วงก่อน–ระหว่าง–หลังนั่งแบบเดิม เจ้าของชอบแล้ว มีทางไปหน้าฝึก
2. เริ่มนั่งสมาธิ: เข้าดวงแก้วและเลือกเสียงได้ทันที → นั่ง → พัก/ทำต่อ → จบรอบ → สรุป ตัวปรับลมหายใจย้ายไปส่วนเลือกเปิดในคู่มือ

ดวงแก้วใสอยู่กลางหน้า แตะเพื่อเริ่ม แตะอีกครั้งพัก แตะตอนพักทำต่อ ตอนพักมีปุ่มทำต่อและจบรอบนี้ ระลอกแผ่จากกลางดวงแก้วเบา ๆ ตัวเลขเวลาซ่อนไว้ให้เปิดดู ไม่ใช่สิ่งเด่นบนหน้า จังหวะตัวอย่างระลอกทุก6วินาที วงรอบครบ1นาที

Timerเริ่มเมื่อเริ่มนั่ง ไม่นับช่วงปรับใจ/พัก จบแล้วfreezeเวลาทันทีและมีระลอกสุดท้าย แสงนุ่ม การ์ดสรุปลอยกลางviewportทั้งหน้า พื้นหลังเว็บกดไม่ได้ การ์ดแสดงเวลานั่งจริงและปุ่มนั่งอีกรอบ/กลับหน้าหลัก ต้องใช้สีสว่างและธีมเว็บจริง navy/cream/gold ไม่ใช้โทนมืดของpreview

รูปแบบเสียงในอนาคต: หยดน้ำกระทบน้ำเบา ๆ โดยไม่มีเสียงพูด กับเสียงนำสมาธิ ใช้ดวงแก้วเดียวกัน เสียงหยดน้ำสังเคราะห์ที่เคยลองไม่ผ่านและเอาออกแล้ว เจ้าของให้ข้ามการหาเสียงไปก่อน มีไฟล์เสียงนำ/คำบรรยายเดิมให้ต่อยอด ยังไม่ทำranking ไม่ทำบัญชีผู้มาเยือนหรือสะสมเวลาข้ามครั้งในรอบนี้

ข้อเสนออาจารย์ในประชุมคือTimer สะสมเวลารายคนเพื่อเห็นความก้าวหน้า และให้ใช้ได้ก่อนค่อยล็อกอินเมื่ออยากบันทึกเวลา ส่วนการทำบัญชีสะสมเวลายังเป็นงานต่อยอด ไม่ใช่ทำเสร็จแล้ว

## งานหลักที่2: เกมสถานการณ์ Monk Chat ส่วนใหม่

แยกจากแฟลชการ์ด คำศัพท์ เกมข้อสอบเดิม และบทฝึกเดิม คงของเดิมไว้ เป้าหมายคือฝึกบทสนทนาต่อเนื่อง เลือกคำพูดแล้วเห็นคู่สนทนาตอบและเหตุการณ์ถัดไปตามทางเลือก ไม่ใช่แค่ตอบA/B/Cแล้วข้ามข้อ

บริบทที่เจ้าของอธิบาย: พระนิสิตไปทำกิจกรรมที่วัด ชวนผู้มาเยือนมานั่ง สนทนาทำความรู้จัก/ถามว่ามาจากไหน ผู้มาเยือนถามเรื่องพระ จีวร โกนผม ชวนสมาธิ เตรียมตัวและนำนั่ง หลังนั่งถามความรู้สึกหรือสิ่งที่อยากเล่า จากนั้นชวนถ่ายภาพหมู่ จัดตำแหน่งและเว้นระยะอย่างสุภาพ แล้วกล่าวลา

แบ่งโครง8บท: เชิญชวน / ต้อนรับ / ชีวิตพระ / ชวนสมาธิ / เตรียมและนำนั่ง / สนทนาหลังฝึก / ภาพหมู่ / กล่าวลา

เกมต้องมีทางที่ผู้มาเยือนปฏิเสธ มีเวลาน้อย ไม่เข้าใจ ขอพูดช้าลง ไม่อยากนั่งสมาธิ หรือไม่อยากถ่ายรูป ให้ฝึกรับมืออย่างสุภาพและแก้ประโยคได้ ทางเลือกเหมาะสมได้มากกว่าหนึ่งแบบ ไม่ทำคะแนนตามเพศหรือสัญชาติ ไม่ชี้นำว่าฝึกแล้วต้องเห็นดวงแก้วหรือรู้สึกสงบ และไม่อ้างผลทางธรรมจากคะแนนเกม

รุ่นแรกใช้ภาพนิ่ง/ภาพร่าง + บทพูดอังกฤษและคำแปลไทย + ตัวเลือก + feedback + ฉากถัดไปก่อน การเดินและanimationทำภายหลัง เจ้าของขอให้วันนี้มีโครงพร้อมส่งต่อ ปัจจุบันมีsample graph24ฉาก36ทางเลือก ตรวจแล้วทุกลิงก์มีปลายทางและทุกฉากมีทางไปจบเรื่อง แต่เนื้อหาเป็นร่างสมมติ ต้องตรวจภาษาและข้อปฏิบัติก่อนเผยแพร่จริง ยังไม่ได้ทำตัวเกมในแอป

## งานเกี่ยวข้องอีกสองเรื่อง
