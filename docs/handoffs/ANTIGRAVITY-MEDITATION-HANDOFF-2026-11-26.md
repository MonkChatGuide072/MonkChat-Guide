### หน้า A — คู่มือเริ่มต้น / Beginner’s Guide

- แยกคู่มือออกจากหน้าฝึกจริง เพื่อไม่ให้หน้ารวมหลายอย่างจนแน่น
- ใช้การ์ดเดิม ภาพเดิม และเนื้อหาเดิม: ก่อนนั่ง ระหว่างนั่ง หลังนั่ง รวมรายละเอียดฐานทั้ง7ที่เปิดดูเพิ่มได้
- คงความน่ารัก อ่านง่าย กระชับตามงานเดิม ห้ามเปลี่ยนภาพหรือเรียบเรียงคำสอนครั้งใหญ่เอง
- มีปุ่มไปหน้าเริ่มนั่ง ไม่บังคับให้อ่านครบก่อนฝึก

### หน้า B — เริ่มนั่งสมาธิ / Meditate Now

- เส้นทาง: เตรียมตัว → ปรับใจด้วยส่วนเดิม → เริ่มนั่ง → พัก/ทำต่อ → จบรอบ → การ์ดสรุป
- พร้อมแล้วข้ามการปรับใจได้ Timer เริ่มเมื่อเริ่มนั่ง ไม่รวมการอ่านหรือปรับใจ
- ดวงแก้วใสกลมเป็นจุดเด่นกลางหน้า แทนตัวเลข Timer ขนาดใหญ่
- แตะ/คลิกดวงแก้วครั้งแรกเริ่มนั่ง แตะอีกครั้งพัก แตะตอนพักทำต่อ
- ตอนพัก แสดงตัวเลือก “ทำต่อ” และ “จบรอบนี้” ไม่จบทันทีเพราะแตะพลาด
- ใช้ native button รองรับ Enter/Space มีชื่อ accessible ตามสถานะ ไม่ทำ div ที่คลิกได้อย่างเดียว
- ระลอกต้องแผ่จากกลางดวงแก้วไปทั่วดวงแก้วอย่างนุ่มนวล เจ้าของชอบรุ่นนี้แล้ว หยดจากด้านบนไม่ใช่สาระหลักที่ต้องคง
- จังหวะตัวอย่าง: ระลอกทุก6วินาที =10รอบต่อนาที วงรอบดวงแก้วครบ1รอบต่อนาที ตัวเลขจริงซ่อนใน “ดูเวลาที่ผ่านไป”
- ระลอกแสดงจังหวะเวลา ห้ามใช้เป็นคะแนนระดับสมาธิ ความบริสุทธิ์ หรือผลทางธรรม
- พักแล้ว Timer ภาพ และเสียงต้องหยุดด้วยกัน ทำต่อแล้วต่อจากเวลาเดิม
- ไม่ต้องสมัคร/ล็อกอินเพื่อเริ่มใช้ รอบนี้แสดงผลครั้งเดียว ไม่เพิ่มระบบสะสมเวลาผูกบัญชีเอง

### จบรอบ: การ์ดสรุปเต็มหน้าจอจริง

- เมื่อตั้งใจเลือก “จบรอบนี้” หยุดเวลาและเสียงทันที ระลอกสุดท้ายค่อย ๆ แผ่ แสงทองอ่อนขึ้นเบา ๆ แล้วการ์ดลอยขึ้นในประมาณ1วินาที
- เจ้าของยืนยันว่าต้องคลุม **viewport ทั้งหน้าเว็บ** ส่วนอื่นเป็นพื้นหลัง การ์ดอยู่กลางจอ ไม่ใช่ overlay เฉพาะกรอบเครื่องเล่นแบบใน mockup
- ใช้ธีมเว็บเดิม: พื้นสว่าง ดวงแก้วใส น้ำเงิน/ทองอ่อน ข้อความและปุ่มชัด คงโทนการ์ดเดิม ไม่ทำสีมืดหรือแสงวาบรุนแรง
- ตัวอย่างข้อความ: “ช่วงเวลาดี ๆ ที่คุณให้ตัวเอง” + เวลานาที/วินาทีจริง + “ค่อย ๆ กลับมา เมื่อคุณพร้อม”
- ปุ่ม “นั่งอีกรอบ” และ “กลับหน้าหลัก” เวลาบนการ์ดต้องตรงกับ Timer รอบที่จบจริง ไม่ใส่เวลาตัวอย่างหรือคะแนนขึ้นเอง
- รองรับ keyboard focus, focus trap, ล็อกการกดพื้นหลัง/scroll, คืน focus เมื่อปิด และ prefers-reduced-motion
- แนะนำใช้ native dialog.showModal หรือ portal ไป body + inert background เพื่อไม่ติด stacking context ของ Layout ที่มี isolate

## 4. เสียงและสิ่งที่พักไว้

- รูปแบบเสียงที่เจ้าของอยากได้ในที่สุดมี2แบบ: (1) ไม่มีเสียงพูด แต่มีหยดน้ำกระทบน้ำเบา ๆ (2) เสียงนำสมาธิ ทั้งคู่ใช้ภาพดวงแก้วเดียวกัน

- ไม่เปลี่ยนฐานข้อมูลหรือสิทธิ์เพียงเพื่อทำ Timer รอบเดียว

1. ใช้ timer state ชัดเจน ready/running/paused/finishing/completed เวลาจริงคำนวณจาก clock + เวลาสะสม ไม่เพิ่มจำนวนวินาทีจาก setInterval อย่างเดียว เพราะ background tab ทำให้ interval ช้า
2. เก็บเวลารอบนี้ใน state ของ session ไม่ใช้เวลา audio.currentTime แทนเวลานั่ง เพราะผู้ใช้ seek/pause หรือเสียงจบก่อนเวลานั่งได้
3. ระบุพฤติกรรมออกหน้า/ซ่อนหน้าให้ชัด อย่างน้อยไม่ปล่อยเสียงเล่นต่อหลัง unmount และไม่ทำค่าหายเงียบ ๆ; ไม่สร้างระบบประวัติถาวรเอง
4. ออกจากหน้าฝึกขณะนั่งควรมีการพักหรือยืนยันที่ไม่ทำให้เวลาหาย รักษา focus และการใช้งานบนมือถือ
5. ถ้า Timer สั่ง audio.play แล้ว browser ปฏิเสธ อย่ารายงานว่าเสียงกำลังเล่น แสดงทางลองใหม่และรักษา Timer ตามสถานะที่อธิบายได้
6. audio/VTT fail ต้องไม่ล้มหน้าคู่มือหรือ Timer เงียบ และไม่ใช้ไฟล์ placeholder example.org เป็นเสียงจริง
7. ปุ่ม native audio ถ้ายังคงไว้ต้องไม่ทำให้ session กับเสียงขัดกัน ตรวจทั้งกดดวงแก้วและกดจาก player โดยตรง
8. ปิดงาน session ก่อนเปลี่ยน track/language อย่าให้เสียงเก่าหรือ callback ที่ตอบช้าเล่นข้ามรอบ
9. การ์ดผลอาจเด้งหลังเอฟเฟกต์ แต่ freeze เวลา ณ ตอนกดจบทันที ไม่เพิ่มอีก1วินาทีระหว่าง animation
10. ครบ1นาทีหรือเสียงจบไม่ควรปิดรอบเอง เพราะไม่มีการตกลงให้ฝึกแบบนับถอยหลังบังคับจบ
