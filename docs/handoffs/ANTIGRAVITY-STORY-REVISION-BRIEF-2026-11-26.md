# บรีฟแก้เกม Monk Chat: เล่าเรื่องด้วยภาพและทางเลือก

> สถานะล่าสุด: สองหน้าสมาธิและการ์ดหลังนั่งเผยแพร่ production แล้วตามคำยืนยันเจ้าของ อ่าน `MEDITATION-PRODUCTION-RELEASE-2026-11-26.md` ข้อความยังไม่deploy/รอเจ้าของดูด้านล่างเป็นประวัติ งานเกมยังอยู่ระหว่างปรับและไม่ได้รวมขึ้นเว็บรอบนี้

บันทึกคำยืนยันเจ้าของล่าสุด 26 พฤศจิกายน 2569 หลังทดลองฉบับแรกของ Antigravity

เอกสารนี้แทนข้อกำหนดหน้าจอและจังหวะการเล่นในบรีฟเกมฉบับก่อน หากข้อมูลขัดกันให้ใช้เอกสารนี้เป็นทิศทางล่าสุด บริบทโครงการและข้อจำกัดด้านงบประมาณ/ความปลอดภัยเดิมยังใช้

## 1. ภาพที่เจ้าของต้องการ

เจ้าของเลือก **Coming Out Simulator** เป็นตัวอย่างของรูปแบบการนำเสนอ: https://ncase.me/cos/

อ้างอิงเฉพาะวิธีเล่าเรื่องด้วยภาพ ตัวละคร และตัวเลือก ไม่คัดลอกเนื้อเรื่อง ตัวละคร ภาพ หรือโค้ดจากเกมต้นแบบ

ผู้เล่นรับบทพระนิสิต เห็นภาพฉากหลักกลางจอ อ่านเหตุการณ์หรือบทพูดสั้น ๆ แล้วเลือกสิ่งที่จะพูดหรือทำ เมื่อเลือก **ภาพและบทสนทนาเปลี่ยนเป็นเหตุการณ์ถัดไปทันที** เรื่องดำเนินต่อจากผลของคำตอบนั้น มีทางแยกและตอนจบที่สัมพันธ์กับสิ่งที่เลือก

ไม่ต้องทำระบบเกมขนาดใหญ่ การเดิน 3D โลกเปิด หรือแอนิเมชันซับซ้อน ภาพนิ่งที่เปลี่ยนตามเหตุการณ์และการเปลี่ยนฉากนุ่ม ๆ เพียงพอสำหรับรุ่นแรก ภาพและบทพูดต้องทำหน้าที่เล่าเรื่องร่วมกัน

คำว่า “การ์ด” ในคำอธิบายล่าสุดหมายถึง **การ์ดภาพฉากหลักที่กำลังเล่นตรงกลางจอ** ไม่ใช่แค่เมนูการ์ดย่อยสำหรับเลือกฉาก

## 2. สิ่งที่ต้องแก้จากฉบับ Antigravity

| ฉบับปัจจุบัน | พฤติกรรมที่ต้องการ |
| --- | --- |
| เริ่มด้วยผู้มาเยือนเข้ามาถามเอง | เริ่มด้วยพระนิสิตประจำจุดกิจกรรม มีคนเดินผ่าน แล้วผู้เล่นเลือกจังหวะและคำชวน |
| วิ่งครบ 8 ช่วงของกิจกรรมในเรื่องสั้นเดียว | แบ่งเป็นบท แต่ละบทมีเหตุการณ์ต่อเนื่องและจบเรื่องย่อยของตนเอง |
| ภาพกิจกรรมมุมกว้างอยู่ข้างกล่องข้อสอบ | ให้ภาพฉากหลักอยู่กลางประสบการณ์ เปลี่ยนภาพ/ท่าทีตามเหตุการณ์ เห็นว่ากำลังคุยกับใคร |
| เลือกคำตอบ → feedback → กดไปฉากถัดไป | เลือกคำตอบ → เปลี่ยนฉากและเห็นปฏิกิริยาทันที → เลือกตอบต่อ |
| คำถามบางข้อถูกข้ามโดยไม่ตอบ | ตอบสิ่งที่อีกฝ่ายเพิ่งถามก่อนเปลี่ยนหัวข้อ |
| สรุปว่าฝึกครบทุกอย่าง | สรุปเฉพาะบท เหตุการณ์และทักษะที่ผ่านจริง ไม่อ้างว่าใช้ภาษาได้คล่องแล้ว |

ยังใช้ component และโครง graph เดิมต่อได้ แต่ต้องแก้ลำดับเรื่องและวิธี render ให้ตรงบรีฟ ไม่จำเป็นต้องรื้อระบบเว็บ

## 3. บริบทจริงของ Monk Chat

พระนิสิตทำกิจกรรมในบริเวณวัดมหาธาตุ อยุธยา บางคนยืนใกล้จุดที่นักท่องเที่ยวเดินผ่านเพื่อเชิญชวน นักท่องเที่ยวอาจเดินคนเดียวหรือเป็นกลุ่ม ยังไม่รู้จักโครงการ หรือมีเวลาจำกัด

คำชวนอาจแนะนำว่าเป็น Ayutthaya Monk Chat พูดคุยกับพระ และมีสมาธิสั้น ๆ ประมาณห้านาที การบอกห้านาทีหมายถึงช่วงสมาธิ ไม่รับปากว่าการพูดคุยและกิจกรรมทั้งหมดเสร็จในห้านาที

เมื่อผู้มาเยือนตอบรับจึงพาไปจุดนั่ง ต้อนรับ ทำความรู้จัก สนทนาเรื่องที่เขาสนใจ อาจชวนสมาธิตามความพร้อม หลังฝึกมีการถามความรู้สึกและรับฟัง อาจชวนถ่ายภาพหมู่โดยขอความยินยอม จัดระยะห่างอย่างสุภาพ และกล่าวลา

แต่ละคนเลือกไม่ร่วมบางกิจกรรมได้ ไม่สมมติว่าทุกคนต้องนั่งสมาธิหรือถ่ายภาพ และไม่ใช้เพศหรือสัญชาติเป็นตัวกำหนดบุคลิกสำเร็จรูป

## 4. โครงบทฝึก

1. **การเชิญชวน** — พระนิสิตเริ่มเข้าหาคนเดินผ่าน อธิบายกิจกรรม รับฟังข้อจำกัด และจบที่ตอบรับหรือกล่าวลา
2. **ต้อนรับเมื่อมานั่ง** — จัดที่นั่ง แนะนำตัว และสร้างความสบายใจ
3. **ทำความรู้จักและตอบคำถามชีวิตพระ** — ถามที่มา สนทนาต่อ ตอบเรื่องจีวรหรือโกนผมอย่างเข้าใจง่าย
4. **ชวนสมาธิ** — อธิบายสิ่งที่จะทำและรับฟังความพร้อม
5. **เตรียมและนำนั่ง** — ฝึกใช้ประโยคแนะนำจริง ไม่ใช่กระโดดจาก “พร้อมแล้ว” ไป “นั่งเสร็จแล้ว”
6. **สนทนาหลังฝึก** — รับฟังความรู้สึก ตอบข้อกังวลโดยไม่ชี้นำว่าต้องเห็นอะไร
7. **ถ่ายภาพหมู่** — ชวน ขอความยินยอม จัดตำแหน่งและระยะอย่างสุภาพ
8. **กล่าวลา** — ปิดบทสนทนาและเสนอข้อมูลต่อเมื่อผู้มาเยือนต้องการ

เริ่มแก้บทที่ 1 ให้ดูและเล่นได้ตรงแนวก่อน แล้วค่อยขยายบทอื่น รายการนี้คือแผนบท ไม่ใช่คำกล่าวว่าทำครบแล้ว

## 5. บทที่ 1: ตัวอย่างจังหวะภาพกับเรื่อง

**ฉากเปิด**: “บ่ายวันหนึ่ง คุณยืนอยู่ใกล้จุดกิจกรรม Monk Chat นักท่องเที่ยวสามคนเดินผ่าน คนหนึ่งมองป้าย อีกสองคนกำลังคุยกัน คุณจะเริ่มอย่างไร?”

ภาพควรเห็นทางเดิน ป้ายกิจกรรม และนักท่องเที่ยวกลุ่มเดิมจากมุมผู้เล่น ไม่ใช้ภาพบรรยากาศวัดเปล่าแทนทุกเหตุการณ์

| จุด | ภาพและเหตุการณ์ | ตัวอย่างประโยค/การกระทำ | ฉากต่อไป |
| --- | --- | --- | --- |
| เริ่มชวน | กลุ่มกำลังเดินผ่าน ยังไม่ได้พูดกับพระนิสิต | “Hello! Would you like to hear a little about Monk Chat?” | คนหนึ่งหันมาหยุดฟังและถามว่า Monk Chat คืออะไร |
| ชวนด้วยสมาธิสั้น | กลุ่มกำลังเดินผ่าน | “Hello! Would you like to try about five minutes of meditation?” | คนหนึ่งมองนาฬิกา ถามว่าห้านาทีรวมพูดคุยด้วยไหม |
| รอจังหวะ | เพื่อนในกลุ่มยังพูดกัน | รอให้คุยจบ สบตาและยิ้มโดยไม่ขวางทาง | คนหนึ่งยิ้มตอบและชะลอเดิน เป็นจังหวะเริ่มแนะนำตัว |
| อธิบายกิจกรรม | กลุ่มหันมาฟัง | “You can talk with monks and try a short meditation if you like.” | เพื่อนคนหนึ่งถามว่าอยากคุยอย่างเดียวได้ไหม |
| เวลาไม่พอ | คนหนึ่งดูเวลา เพื่อนยังรอ | “Five minutes is the meditation itself. When do you need to leave?” | ได้คำตอบเรื่องนัดหมาย แล้วจึงเสนอคุยสั้น ๆ หรือกล่าวลา |
| ความต้องการต่างกัน | บางคนสนใจ บางคนลังเล | “Meditation is optional. Would you like to start with a conversation?” | กลุ่มปรึกษากันแล้วตอบรับมาคุยก่อน |
| เผลอเร่ง | ผู้เล่นเลือกคำพูดที่ฟังเหมือนให้รีบเข้ามา | ผู้มาเยือนถามว่า “Do we have to join now?” | มีทางขอโทษ อธิบายใหม่ หรือกล่าวลาอย่างสุภาพ |
| ตอบรับ | กลุ่มหันไปทางที่นั่ง | ชี้ที่นั่งและบอกว่าจะเริ่มจากพูดคุยตามที่ตกลง | จบบท 1 ที่การเชิญชวนสำเร็จ ไม่เริ่มสมาธิทันที |
| ไม่เข้าร่วม | กลุ่มเตรียมเดินต่อ | “Of course. Enjoy your visit.” | ภาพกลุ่มเดินต่อและจบบทอย่างสุภาพ ไม่ขึ้นว่าล้มเหลว |

ตัวอย่างเป็นบทพูดร่างสำหรับตรวจ ไม่ใช่บทสนทนาที่บันทึกจากผู้ร่วมกิจกรรมจริง เส้นทางไม่ต้องมีคำตอบถูกข้อเดียว ตัวเลือกควรต่างกันอย่างมีเหตุผล บางทางมีโอกาสแก้คำพูด ไม่ใช้แต่ตัวลวงหยาบคายที่เดาคำตอบได้ทันที

**ความต่อเนื่องสำคัญ**: ถ้าคนเดิมเริ่มถามเรื่องเวลา ฉากถัดไปยังเป็นคนเดิมและตอบข้อจำกัดนั้น ไม่เปลี่ยนเป็นเหตุการณ์ที่ไม่เกี่ยวกันหรือสุ่มคำตอบตามชื่อปุ่ม

## 6. การจัดหน้าจอ

หน้ารวมบทเลือกได้ว่าจะเริ่มฝึกบทไหน แต่เนื้อที่หลักขณะเล่นเป็น **ฉากหนึ่งฉากต่อหนึ่งหน้าจอเล่น**

ลำดับองค์ประกอบ:

1. ชื่อบทกับปุ่มออกขนาดเล็ก ไม่ใช้แถบอธิบายยาวนำหน้าทุกฉาก
2. ภาพหลักกลางจอ เป็นจุดสนใจ ใช้กรอบที่สม่ำเสมอ
3. ข้อความเล่าเรื่อง 1–3 ประโยค หรือชื่อผู้พูดพร้อมบทพูด
4. ทางเลือก 2–3 ข้อใต้ภาพ/กล่องบทพูด แตะสะดวกบนมือถือ
5. เมื่อแตะ ให้ทางเลือกของฉากเก่าหาย เปลี่ยนภาพและเนื้อหาไปฉากใหม่ทันที ป้องกันการแตะซ้ำระหว่างเปลี่ยน

ไม่เปิด feedback แบบข้อสอบมาคั่นทุกคำตอบ หากต้องมีคำอธิบายการเรียนรู้ ให้เป็นตัวเลือกอ่านเพิ่มเติมที่ไม่ขัดจังหวะ หรือรวบรวมในหน้าทบทวนตอนจบบท

ภาพนิ่งใช้ได้ ไม่ต้องมี animation ทุกฉาก แต่เหตุการณ์ที่เปลี่ยนชัดเจนต้องมีภาพ/ท่าทีที่สื่อการเปลี่ยน เช่น เดินผ่าน → หยุดฟัง → ลังเลดูเวลา → เดินไปที่นั่ง ภาพเดียวกันใช้ซ้ำได้เมื่อยังเป็นสถานการณ์เดิม ไม่เพียงเปลี่ยนหัวข้อบนภาพเดิมตลอดบท

## 7. แนวกราฟิก

- คงธีม navy / cream / soft gold ของเว็บและความสุภาพเหมาะกับพระนิสิต ไม่เปลี่ยนธีมทั้งเว็บ
- ภาพประกอบชุดเดียวกัน ตำแหน่งวัด ตัวละคร เสื้อผ้าและสัดส่วนต่อเนื่อง ให้เห็นว่าเป็นกลุ่มเดิม ไม่สลับภาพคนละคนโดยไม่มีคำอธิบาย
- ใช้ภาพวาดฉากหรือตัวละครที่เหมาะกับผู้ใหญ่ สีอ่านง่าย ไม่ใช้ emoji จำนวนมากเป็นตัวแทนงานออกแบบ
- ไม่ต้องถ่ายใหม่หรือสร้างภาพครบ 8 บทก่อน เริ่มฉากหลักของบท 1 ให้เห็นลำดับภาพจริง
- หากยังเป็นภาพร่างให้รายงานว่าเป็นภาพร่าง ไม่กล่าวว่าเป็นงานกราฟิกสมบูรณ์แล้ว
- การเปลี่ยนฉากสั้นและนุ่มนวล รองรับ reduced motion ไม่ใช้เอฟเฟกต์แสงวาบหรือภาพเคลื่อนไหวบังคับ
- อ้างอิงรูปแบบจาก Coming Out Simulator ได้ แต่ต้องใช้ภาพและเรื่องของ Monk Chat เอง

## 8. แบ่งงานให้ Antigravity รับช่วง

**R1 เนื้อเรื่องบทแรก**: เขียนฉากเปิด ทางเลือก ปฏิกิริยา ทางแก้ และตอนจบของการเชิญชวนให้ครบ ตรวจความต่อเนื่องก่อนเพิ่มบทอื่น

**R2 วางภาพแต่ละฉาก**: ทำ scene list ว่าแต่ละ node ใช้ภาพอะไร ตัวละครอยู่จุดไหน และภาพเปลี่ยนเพราะเหตุการณ์อะไร เตรียมภาพร่างชุดเดียวกันให้ลองเล่นได้

**R3 ปรับตัวเล่น**: เปลี่ยนจากแบบข้อสอบสองคอลัมน์เป็นภาพฉากกลางจอและบทสนทนา เลือกแล้วเดินเรื่องทันที ไม่ต้องกด feedback แล้วกด next อีกครั้ง

**R4 สรุปเฉพาะบท**: แสดงเส้นทางที่เลือก ประโยคสำคัญ และข้อเสนอแนะตามเหตุการณ์จริง ย้อนลองจากจุดตัดสินใจได้ ไม่อ้างว่าฝึกครบ 8 บทหรือพร้อมใช้งาน 100%

**R5 ป้องกันผลหาย**: หากความคืบหน้าอยู่เฉพาะรอบนี้ ให้แจ้งก่อนเริ่มใหม่หรือออก ไม่แสดงว่าบันทึกบัญชี/cloudแล้วหากยังไม่มีการเก็บจริง

## 9. เงื่อนไขตรวจรับบทแรก

- คำถามเรื่องเวลาหรือกิจกรรมได้รับคำตอบก่อนเปลี่ยนหัวข้อ
- ตอนจบยังอยู่ในขอบเขตการเชิญชวน ไม่กระโดดจบทั้งกิจกรรม Monk Chat

- คง flashcards เกมข้อสอบเดิม โมดูลอื่น CMS สมาธิ และสิทธิ์บัญชีเดิม
- ไม่เพิ่ม paid API ระบบ ranking ฐานข้อมูลใหม่ หรือแก้เล่มภาคนิพนธ์ในงานนี้
