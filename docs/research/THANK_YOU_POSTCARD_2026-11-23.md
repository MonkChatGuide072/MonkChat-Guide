# การ์ดขอบคุณ Monk Chat แบบโปสการ์ด

## การ์ดขอบคุณแบบโปสการ์ดอยุธยา — 23 พฤศจิกายน 2569

- เจ้าของขอให้การ์ดขอบคุณน่ารักและมีเอกลักษณ์ จึงเปลี่ยนเป็นโปสการ์ดภาพเวกเตอร์สวนร่มไม้ พระปรางค์ และวงสนทนา มีขอบเย็บลายจุด ใบไม้ ดอกบัว และตรารอยยิ้ม เลือกได้ 3 โทน: สวนร่มไม้ แสงอุ่นอยุธยา และบัวละมุน
- คงชื่อผู้มาเยือน วันที่ ชื่อพระผู้สนทนา ข้อความขอบคุณ 2 แบบเดิม และบันทึกชื่อเฉพาะเครื่อง ภาพเป็นภาพตกแต่ง ไม่ใช่หลักฐานการเข้าร่วมหรือใบรับรอง ภาพต้นแบบไม่มีชื่อผู้เข้าร่วมจริง
- ใช้ `ThankYouPostcard.tsx` เป็น SVG ต้นฉบับเดียวทั้งพรีวิวและ PNG 1200×1500 จึงไม่วาดรูปส่งออกซ้ำอีกชุด แยกข้อมูลสีและจัดบรรทัดใน `src/content/thankYouPostcard.ts` เพิ่มสถานะกำลังสร้าง ข้อผิดพลาด และลิงก์เปิดภาพที่สร้างแล้ว คืน Blob URL เมื่อเปลี่ยนไฟล์/ออกจากหน้า
- ผลตรวจ: lint ไม่มี warnings, TypeScript/production build ผ่าน, 120 tests ใน 20 ไฟล์ผ่าน รวมชื่อยาว ภาษาไทย และ markup เป็นข้อความ ตรวจ 3 โทนที่ 360/390/768/1024/1440 px รวม 15 สถานะ ไม่พบหน้าเว็บล้นแนวนอน
- ตรวจ UI สร้าง PNG Blob แล้วและแสดงสถานะพร้อมบันทึก การรับไฟล์ผ่านเครื่องมือดาวน์โหลด timeout และ Browser Use บล็อกการเปิด Blob URL จึงไม่ตรวจผ่านทางนั้นต่อ/ไม่อ้อมนโยบาย ตรวจภาพโดยตรงจาก inline SVG ในหน้าเว็บ และไม่อ้างว่าเปิดไฟล์ PNG ที่บันทึกลง OS เพื่อตรวจแล้ว
- ภาพพรีวิวทั้ง 3 โทน ผลตรวจ และ patch เฉพาะรอบนี้อยู่ `outputs/thank-you-postcard-2026-11-23/` ใน Documents สำรอง component ก่อนแก้ไว้ `.tmp/thank-you-card/before/` ไม่เพิ่ม dependency ไม่แก้ DB/Auth/สื่อเสียง ไม่ commit/push/deploy
