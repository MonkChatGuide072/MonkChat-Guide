# แผนทดลองใช้งาน MonkChat Guide สำหรับพระนิสิต

ฉบับเตรียมทดลอง วันที่ 18 พฤศจิกายน 2569

## จุดประสงค์

ตรวจว่าพระนิสิตเข้าถึงสื่อ ฝึกตอบคำถาม และเตรียมบทนำสมาธิได้ตามงานที่กำหนด พร้อมบันทึกข้อขัดข้องและความเห็นหลังใช้ เพื่อนำไปปรับระบบและเขียนผลการพัฒนา การใช้ต้นแบบสำเร็จไม่ใช่หลักฐานโดยตัวเองว่าความสามารถภาษาอังกฤษหรือความพร้อมหน้างานเพิ่มขึ้น

## ก่อนเริ่มแต่ละรอบ

- ระบุเวอร์ชันเว็บ วันเวลา สถานที่ และผู้ดำเนินการตามจริง
- ผู้ทดลองยินยอมก่อนเก็บข้อมูล ใช้รหัสสำหรับวิเคราะห์และเก็บตารางเทียบชื่อแยกจากตารางผล
- ตรวจอินเทอร์เน็ต ลำโพง/หูฟัง และการเล่นเสียงบนอุปกรณ์จริง
- ระบุรหัสผู้ฝึกให้ถูกก่อนเริ่ม หากหน้าจอเป็น `AYT-MONK` ให้ถือเป็นรอบสาธิต ไม่ใช้แทนรายบุคคล
- แยกรอบอธิบายวิธีใช้/รอบตรวจระบบออกจากรอบที่นำไปวิเคราะห์

## งานที่ให้ทดลอง

| งาน | สิ่งที่ผู้ทดลองทำ | สิ่งที่ผู้สังเกตบันทึก |
| --- | --- | --- |
| เข้าถึงชุดฝึก | เปิด QR/ลิงก์ เข้าหน้า /nisit และหาหมวดที่กำหนด | สำเร็จด้วยตนเอง/ต้องช่วย/ไม่สำเร็จ เวลาและสาเหตุ |
| ฝึกคำศัพท์ | เปิดหนึ่งบท อ่านประโยค กดฟัง และทำเครื่องหมายฝึก | ความเข้าใจปุ่ม ภาษา การเล่นเสียงและข้อขัดข้อง |
| เสียงและบทอ่าน | เล่น หยุด เลื่อนเวลา และเปิดบทอ่านตามที่กำหนด | เสียงดังจริง โหลดได้หรือไม่ บทอ่านข้ามไปตำแหน่งที่เลือกหรือไม่ |
| Q&A | หาหมวด เปิดคำถาม ลองตอบก่อนเปิดแนวคำตอบ | ค้นเจอหรือไม่ ถ้อยคำที่ไม่เข้าใจและคำตอบที่ต้องทบทวน |
| สถานการณ์ | ทำหมวดเดิมที่ผู้วิจัยกำหนดจนจบหนึ่งรอบ | จำนวนข้อ ถูก คะแนน เวลา และจำนวนครั้งที่ช่วย |
| ตรวจประวัติ | เปิดหน้าประวัติและส่งออก CSV | จำนวนแถว รหัส คะแนนตรงจอหรือไม่ |
| จดคำถาม | บันทึกคำถามตัวอย่างในเครื่อง | ผู้ทดลองเข้าใจหรือไม่ว่ายังไม่ได้ส่งถึง CMS |

หากจะใช้เสียงระหว่างกิจกรรม ต้องยืนยันขอบเขตก่อน การทดลองช่วงเตรียมตัวให้ใช้หูฟังหรือพื้นที่ฝึกที่เหมาะสม ไม่รวมผู้มาเยือนเป็นกลุ่มตัวอย่างโดยอัตโนมัติ

## หลังแต่ละคนทดลอง

1. ส่งออก CSV ทันที ตั้งชื่อไฟล์ตามรหัสรอบและวันที่ เก็บไฟล์ต้นฉบับโดยไม่แก้คะแนน
2. บันทึกผู้ทดลองจริงกี่คนและแต่ละคนฝึกกี่รอบ แยกคนกับ attempts
3. ถามความเห็นอย่างเป็นกลาง เช่น “ส่วนใดใช้ได้สะดวก”, “ส่วนใดติดขัด”, “หากต้องเตรียมตัวครั้งต่อไปจะเลือกใช้ส่วนใด เพราะอะไร”
4. ถามความง่ายในการใช้และประโยชน์ที่รับรู้แยกข้อ ไม่สรุปความมั่นใจจากคะแนนแบบฝึกโดยอัตโนมัติ
5. บันทึกปัญหาที่เกิดขึ้นจริงพร้อมหน้า ขั้นตอน อุปกรณ์ และผลที่คาด/ผลที่เกิด ไม่เติมข้อมูลช่องที่ไม่ได้เก็บ

## วิธีสรุปเพื่อเขียนบทที่ 4

- ผลพัฒนาระบบ: นำเสนอหน้าที่มีจริง ภาพรุ่นที่ทดลอง และการทำงานที่ตรวจได้
- ผลใช้งาน: จำนวนและร้อยละที่ทำงานสำเร็จ พร้อมฐานคนที่ได้รับงานแต่ละงาน เวลามัธยฐาน/ช่วงตามข้อมูลจริง
- ผลแบบฝึก: คะแนนคำนวณจากตอบถูก/จำนวนข้อ รายงานครั้งแรกกับรอบฝึกซ้ำแยกกัน ไม่รวมซ้ำเป็นคนใหม่
- หากมีการวัดก่อน–หลัง ให้จับคู่รหัสคนเดิม กำหนดแบบทดสอบและเกณฑ์วัดล่วงหน้า พิจารณาผลการจำข้อเดิม และรายงานเฉพาะผลที่วิธีเก็บรองรับ
- ความเห็นปลายเปิด: จัดกลุ่มประเด็นที่พบจริง พร้อมข้อความตัวอย่างที่ไม่ระบุตัวบุคคล ไม่แปลงรอบทดสอบซอฟต์แวร์เป็นความเห็นผู้เข้าร่วม

## ข้อความตั้งต้นสำหรับรายงานความก้าวหน้า

ได้พัฒนาระบบต้นแบบ MonkChat Guide สำหรับสนับสนุนการฝึกและเตรียมตัวของพระนิสิต โดยมีชุดฝึกสถานการณ์ คำศัพท์ภาษาอังกฤษ สื่อเสียงพร้อมบทอ่าน คลังคำถาม–คำตอบ และการบันทึกผลฝึก ผู้พัฒนาได้ตรวจการทำงานด้วยชุดทดสอบอัตโนมัติและทดลองลำดับการใช้งานในเบราว์เซอร์ ขั้นตอนถัดไปคือทดลองใช้งานกับพระนิสิตตามแผนที่กำหนด เพื่อประเมินความสะดวกในการใช้งาน ประโยชน์ที่รับรู้ และข้อขัดข้องจากการใช้งานจริง

ข้อความนี้ใช้บอกความก้าวหน้าได้ โดยยังไม่อ้างผลเพิ่มทักษะหรือความพึงพอใจที่ไม่ได้เก็บ
