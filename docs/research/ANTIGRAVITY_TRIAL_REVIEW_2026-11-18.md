## เงื่อนไขที่ยังต้องปิดก่อนเก็บข้อมูลสนาม

1. ยืนยันบทบาทเสียง: เคยตกลงว่าใช้เฉพาะฝึก/เตรียมตัว แต่ source Antigravity มีปุ่มเปิดเสียงระหว่างกิจกรรม คำถามชี้แจงถูกส่งแล้วและยังไม่มีคำตอบในรอบตรวจนี้ จึงยังไม่เปลี่ยนขอบเขตเสียงแทนเจ้าของ
2. ทดสอบบัญชีจริงหลัง backend รับชุดใหม่: สมัครทั้งโหมดเปิด/รออนุมัติ, ผู้ดูแลอนุมัติ, student อ่านผลตัวเอง, เข้าหน้า /admin ไม่ได้, บัญชีระงับไม่เขียน progress
3. ทดสอบเสียงกับไฟล์จริงบนมือถือที่จะใช้ รวมเริ่ม/หยุด/เลื่อนเวลาและบทอ่าน ยังไม่รับรองความตรงเวลาของทุก cue จากการอ่านโค้ดเพียงอย่างเดียว
4. โค้ด PWA ยังไม่ precache MP3 และไม่มี runtime cache เสียง จึงยังไม่รับรองคำอ้างว่าเล่นเสียงออฟไลน์ได้ 100% การทดลองรอบแรกควรมีอินเทอร์เน็ตและทดสอบเครือข่ายจริงก่อนเริ่ม

## ขั้นตอนรับชุดแก้ขึ้นระบบสำหรับทดลอง

1. ตรวจ diff ใน branch นี้และสำรองข้อมูลตามกระบวนการโครงการ
2. Apply เฉพาะ migration ใหม่บนโปรเจกต์ที่ยืนยันแล้ว โดยตรวจ migration เดิมว่าครบ

6. บันทึก source commit/deployment ID/วันเวลา/เครื่องที่ใช้ เพื่อให้ภาพและตารางในภาคนิพนธ์ตรงกับรุ่นที่ทดลอง
