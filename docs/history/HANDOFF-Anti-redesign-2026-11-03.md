# MonkChat Guide — สรุปส่งต่องานล่าสุด

ปรับปรุงวันที่ 25 ตุลาคม 2569 ก่อนเริ่มงานให้อ่าน AGENTS.md และ CURRENT_SCOPE.md ร่วมกับไฟล์นี้ บันทึกเก่าทั้งหมดถูกเก็บไว้ตามเดิมใน docs/history/HANDOFF-through-2026-10-25.md เพื่อใช้อ้างอิงประวัติ

## ทิศทางของโครงการ

- พระนิสิตเป็นผู้ใช้หลัก ชาวต่างชาติเข้าดูข้อมูลกิจกรรมและถามคำถามผ่านเว็บสาธารณะ
- แชทบอทต้องตอบจากคำตอบที่เตรียมและตรวจแล้ว ไม่ใช้ AI สร้างคำตอบขณะใช้งาน ส่วน Codex และ Antigravity เป็นเครื่องมือช่วยพัฒนาโครงการ
- ข้อเสนออาจารย์ล่าสุดมีหน้าแจ้งกิจกรรม คู่มือรูปฐานทั้ง 7 คู่มือเริ่มสมาธิ คำถามประเมินสั้น ๆ การเลือกเสียง และ Experience Card รายละเอียดที่ยังไม่ตกลงอยู่ใน CURRENT_SCOPE.md
- BDT001 และ REQUIREMENTS.md เป็นข้อมูลตอนเริ่ม ห้ามนำส่วนที่ขัดกับคำยืนยันล่าสุดมาทำต่อโดยอัตโนมัติ

## งานถัดไป

งานถัดไปคือส่งมอบรายงานและภาพหน้าจอให้เจ้าของโครงการตรวจรับ หากได้รับความเห็นชอบ จึงสร้าง ZIP ชุดรหัสล่าสุดบน Desktop หรือจัดเตรียม Git checkpoint เมื่อเจ้าของโครงการสั่งการ

## ข้อความส่งต่อสำหรับ Antigravity

ให้เริ่มจาก AGENTS.md, CURRENT_SCOPE.md และส่วนสถานะล่าสุดใน HANDOFF.md แล้วตรวจ Git status ก่อนแก้โค้ด โฟลเดอร์หลักของโครงการคือ Desktop/web/monkchat-guide เว็บจริงยังเป็น FAQ เดิม ส่วนการ์ดแชทบอทและการซ่อนรายละเอียดการตรวจอยู่เฉพาะในเครื่อง ห้ามใช้ AI สร้างคำตอบในเว็บ และห้ามย้อนกลับไปแทน FAQ ด้วยแชทบอท ให้ทำงานถัดไปตามหัวข้อข้างต้น ไม่ใช้ migration กับฐานข้อมูลจริงและไม่ commit หรือเผยแพร่จนเจ้าของโครงการสั่ง

## สิ่งที่ต้องบันทึกทุกครั้งก่อนส่งต่องาน

1. ระบุสาขา Git จุดเริ่ม และไฟล์ที่ยังแก้ค้าง แยกสิ่งที่ขึ้นเว็บแล้ว สิ่งที่อยู่เฉพาะในเครื่อง และสิ่งที่ยังไม่ได้ตรวจ
2. ระบุเป้าหมายที่เจ้าของตกลง ไฟล์ที่เปลี่ยน และเนื้อหาธรรมะหรือสิทธิ์สื่อที่ยังรอตรวจ
3. ระบุการตรวจที่ทำจริงและความเสี่ยงที่เหลือ ไม่เอาผลตรวจเก่ามาอ้างแทนงานใหม่
4. ระบุงานถัดไปเพียงงานเดียวที่มีขอบเขตชัด และเรื่องที่ยังต้องให้เจ้าของตัดสิน ห้ามใส่รหัสผ่านหรือกุญแจระบบในไฟล์
5. ให้ AI เพียงตัวเดียวแก้โครงการในช่วงเดียวกัน ห้าม commit, push หรือเผยแพร่หากเจ้าของโครงการยังไม่ได้สั่งและยังไม่ผ่านกฎของโครงการ
